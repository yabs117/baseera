Baseera browser extension

Translate pages in place

  1. Extract the ZIP to a permanent folder.
  2. Open chrome://extensions or edge://extensions.
  3. Turn on Developer mode and choose Load unpacked.
  4. Select the inner extension folder containing manifest.json.
  5. Open an ordinary web page, open the Baseera extension, then enter your Gemini key and model ID.

Your key stays in browser session memory. The extension only sends page text to Google when you request translation. Change the interface language under Settings in the popup.

The Windows app is available from GitHub Releases. Load the browser extension through the extensions page as described above.
