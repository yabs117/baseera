BASEERA · OPTIONAL BROWSER EXTENSION

Translate pages in place.

This package is installed inside Chrome or Edge. Do not double-click module files. They are source code, not Windows programs.

  1. Extract the entire ZIP to a permanent folder.
  2. Type chrome://extensions or edge://extensions into your browser's address bar.
  3. Enable Developer mode, then select Load unpacked.
  4. Select the inner extension folder, the one containing manifest.json.
  5. Open an ordinary web page, click the Baseera extension, and enter your Gemini key and model ID.

Your key lasts for the browser session. Page text is sent to Google only when you request translation.

Looking for the Windows app? Download the Windows package here and open Baseera.exe.

هذه إضافة متصفح وليست تطبيق ويندوز

لا تفتح ملفات الشيفرة بالنقر المزدوج. ظهور Windows Script Host يعني أنك فتحت ملف مصدر برمجي خارج المتصفح.

  1. فك ضغط الحزمة كاملة.
  2. اكتب chrome://extensions أو edge://extensions في شريط عنوان المتصفح.
  3. فعّل وضع المطوّر ثم اختر «تحميل إضافة غير محزّمة».
  4. حدد مجلد extension الداخلي الذي يحتوي على manifest.json.

لتشغيل تطبيق ويندوز نزّل حزمة Windows من الرابط أعلاه ثم افتح Baseera.exe.
