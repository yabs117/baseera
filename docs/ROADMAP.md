# Capability status

## Implemented preview

- WPF desktop shell, collapsible vector-icon navigation, light/dark appearance.
- First-run opt-in features, Arabic RTL, English, French, Spanish.
- Bounded recursive ZIP inspection and folder scanning without extraction.
- SHA-256, PE headers, executable/writable sections, content-based script indicators.
- Open-window capture, 20 direct AI services for vision translation and dismissible overlay.
- Error assistant with visible pasted/selected/captured image preview and service model discovery and image-capable model selection.
- Official ChatGPT account sign-in, account picker, protected OAuth sessions, renewal, revocation, plan-use notices and account model selection.
- Feedback and bug reporting through a prefilled GitHub issue reviewed in the browser.
- Chrome/Edge extension for in-place text replacement and original restoration.
- Selected WinGet packages updated on app start and every six hours while open.
- Baseera self-update checks, in-app download/progress, digest verification, same-path replacement, restart acknowledgement and rollback backup.
- Per-package manual release URL override, GitHub release discovery, reviewed download links.
- PNG/JPEG/BMP/TIFF conversion, ordered multi-image PDF, quality selection.
- Opt-in Explorer context command and Ctrl + right-click on selected images while running.
- Opt-in sign-in launch and startup scan of a configured file/folder.

## Not complete

- RAR/7z support, unpacking obfuscated executables, dynamic behavior analysis in disposable VMs.
- Antivirus engine integration and independently measured false-positive/false-negative rates.
- Continuous translation, global translation hotkey, local OCR.
- Overlay tracking after window movement, click-through interaction, exclusive-fullscreen games,
  protected windows, and comprehensive mixed-DPI/multi-monitor validation.
- General website release adapters and trusted unattended custom-source installation.
- Modern Windows 11 compact Explorer menu extension (current normal menu is in Show more options).
- WebP, document conversion beyond images, animations and multipage-image preservation.
- Signed releases/installer, tray lifecycle, MSIX/store distribution, transactional browser-extension updates.

The initial version is a usable development baseline. An OSS support application
must describe the project as new and must not claim adoption, stars, security
assurance, or maintainer history that has not occurred.
