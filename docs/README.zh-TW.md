# Baseera

一套開放原始碼的 Windows 工具，協助你進行日常維護與問題排查。

[English](../README.md) · [العربية](README.ar.md) · [Español](README.es.md) · [Français](README.fr.md) · [简体中文](README.zh-CN.md) · **繁體中文** · [Tiếng Việt](README.vi.md)

- **下載的檔案有疑慮，或 Windows 出現錯誤？** 在本機檢查檔案與 ZIP 壓縮檔，或將錯誤訊息或螢幕擷取畫面交給 Smart Repair，瞭解可能的原因及後續處理方式。
- **看不懂應用程式的介面語言？** 選取一個 Windows 視窗，翻譯其中看得到的文字。
- **每天有不少維護工作？** 用同一套工具管理指定應用程式的更新、轉換圖片，或將多張圖片合併成 PDF。

**[下載 Windows 版](https://github.com/yabs117/baseera/releases)** · [使用指南（英文）](USER-GUIDE.md) · [版本變更記錄（英文）](CHANGELOG.md)

適用於 Windows 10 和 11（x64）。提供預覽版，內含 .NET 執行階段。

繁體中文介面從 6.5.0 版開始提供。下載前，請查看版本資訊，確認該版本是否已發佈。在支援的版本中，可到 **設定 → 外觀和語言** 切換。

檔案檢查與圖片轉換都在本機完成。AI 功能使用你設定的服務，只會傳送你選擇分享的內容。執行修復前會先徵求你的同意。
