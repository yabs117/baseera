# Baseera

一款开源的 Windows 工具箱，帮助你完成日常维护和故障排查。

[English](../README.md) · [العربية](README.ar.md) · [Español](README.es.md) · [Français](README.fr.md) · **简体中文** · [繁體中文](README.zh-TW.md) · [Tiếng Việt](README.vi.md)

- **下载的文件可疑，或 Windows 出现报错？** 在本机检查文件和 ZIP 压缩包，或将错误文字或截图交给 Smart Repair，了解可能的原因和后续操作。
- **看不懂应用的界面语言？** 选择一个 Windows 窗口，翻译其中可见的文字。
- **有多项日常维护要做？** 在同一个工具箱里管理所选应用的更新、转换图片，或将多张图片合并为 PDF。

**[下载 Windows 版](https://github.com/yabs117/baseera/releases)** · [使用指南（英文）](USER-GUIDE.md) · [更新日志（英文）](CHANGELOG.md)

适用于 Windows 10 和 11（x64）。提供预览版，内置 .NET 运行时。

简体中文界面从 6.5.0 起提供。下载前，请查看发行说明，确认该版本是否已发布。在支持的版本中，打开 **设置 → 外观和语言** 即可切换。

文件检查和图片转换在本机完成。AI 功能使用你配置的服务，只发送你选择共享的内容。执行修复操作前会征求你的同意。
