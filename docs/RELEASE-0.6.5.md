# Baseera 0.6.5 Preview

## Appearance

- Choose green, graphite, red or blue under **Settings → Appearance and language → App colors**. The app previews each option and saves your selection. Light and dark appearance work with all four palettes.
- The sidebar matches the eye logo. Click the eye for a short blink. Baseera respects the Windows high-contrast and animation settings.

## Feedback

- Use **Send feedback** to submit the type, title and details from the app. The form blocks duplicate clicks while a request is in flight.
- A confirmed submission clears the title and details. A connection or server failure keeps the draft available for another attempt.

## Download and update

Download `Baseera.exe` for Windows 10/11 x64, or extract `Baseera.zip`. The .NET runtime is included. The browser extension is optional. Check `SHA256SUMS.txt` to verify the downloads. This preview executable is unsigned.

To update an existing copy, open **Settings → Baseera updates** and check for updates on the Preview channel. The versioned executable is an identical copy for older in-app updaters.

Feedback tests use simulated HTTP responses. They do not send reports to the production service.
